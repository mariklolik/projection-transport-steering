# IRC measurement and allocation amendment

2026-09-07. Prospective amendment to `benchmark-reset-v1.md`, before new MATH model outputs, allocation or duplicate-count inspection. It changes the primary scoring endpoint explicitly; it does not change a success threshold, generation cap, sample quota or closed experiment.

## Measurement decision

The primary endpoint is **author-normalized MATH answer score under the declared generation budget**. Call unchanged functions from `hendrycks/math@985bdc1696e88e8643f081a0ff4719da39f2ae2a`: `last_boxed_only_string`, `remove_boxed`, and `is_equiv`. Require nonempty extracted references for admission and nonempty extracted predictions plus EOS termination for credit. Missing, malformed, empty and budget-exhausted predictions score zero. Do not repair source solutions or introduce another answer grammar.

The independent measurement critic reproduced four author-extraction failures in the 7,500 training records: two braceless answers (`algebra:888`, `algebra:1011`) and two empty boxes (`number_theory:661`, `number_theory:663`). The other 7,496 self-match. A self-match is a coverage check, not a proof of semantic grading. Apply the same nonempty-reference rule mechanically to test references before outcomes; admission requires exclusions below 1% in each original split. Publish all excluded IDs, reasons and hashes, not their answers.

Keep the existing `score_math_completion` unchanged as a fixed sensitivity endpoint: Math-Verify 0.9.0, author last-box extraction, units=False, LaTeX-only anchored parsing, no fallback, first match, strict=True, five-second parsing and verification timeouts, raise_on_error=True. Its remaining upstream defaults are float_rounding=6, numeric_precision=15 and allow_set_relation_comp=False. Freeze its reference-support set mechanically before model outputs. Report both graders' paired effects on that same supported subset, coverage, and the primary effect on the entire admitted panel. Prediction-side exceptions are retained technical failures, never grounds to regenerate a completion or silently remove a row. Catch Math-Verify's explicit TimeoutException, which inherits BaseException.

Neither endpoint certifies arbitrary semantic equivalence. The author's score can reject algebraic equivalents, discard earlier multipart boxes and ignore changed units or short equation left sides. Math-Verify has different errors, including tuple/set comparisons, multi-box extraction and heterogeneous reference parsing. These limits are retained from the independent audit, not fixed with question-specific exceptions. If the direction of a method comparison changes across the two endpoints, report measurement sensitivity and withhold a robust mathematical-correctness claim. Do not select the better grader after results.

For reference-excluded fraction q and admitted-panel paired difference d, report the original-frame bound [(1-q)d-q, (1-q)d+q]. This bound concerns reference exclusions, not the deliberate deduplicated/unexposed target population. Report those populations separately. Existing historical AIME outcomes remain unchanged and exploratory.

## Duplicate and exposure policy

Normalize problem text by Unicode NFC, strip ends and collapse whitespace. Preserve case, numbers, symbols and punctuation. Exact identity uses SHA-256 of normalized text. Near identity uses character 5-gram TF-IDF with lowercase=False, standard smooth IDF and L2 normalization; link pairs whose cosine similarity is at least 0.95. Fit vocabulary/IDF on sorted unique normalized problem texts in the declared audit frame, never solutions or model outputs; texts shorter than five characters receive exact matching only. Use connected components of the undirected similarity graph, identified by the minimum normalized-text SHA-256. This is a conservative lexical-overlap screen, not proof that paraphrases or pretraining contamination are absent.

Exclude an entire component from training and test if it intersects the historical exposure inventory. Treat all MATH-500 and historical/temporal AIME source questions as conservatively exposed, even where old sealed allocations were not actually evaluated. Include the source project's MMLU, ARC, GSM8K and GPQA question frame and available prior target input packets; the manifest must distinguish full-source conservative exclusions from verified actual exposure. Do not claim this inventory complete until its sources are resolved. GSM8K's earlier use prevents calling its full test set a fresh confirmatory endpoint; any later GSM8K result must be marked previously exposed generalization unless an independently unexposed subset is established.

Exclude test components intersecting any official MATH training question, including reserve and reference-ineligible questions. Keep one eligible representative per remaining component, chosen by the lowest stable source-row ID, independently of answer content and model outcomes. Reference-ineligible rows do not become representatives. Allocate training components with existing `allocate_groups`, salt `irc-20260907`, in this fixed quota order: fit 1500, response 512, selection 256, development 256. Remaining eligible training components are reserve. The response pilot is the first 128 response components in the same salted hash order, not sorted by performance. The primary test must retain at least 3000 independent components. If a quota or minimum cannot be met, report that fact before outputs; do not adapt the threshold or cherry-pick rows.

Write all source hashes, normalized-problem hashes, solution hashes, component membership, exclusion reasons, selected representatives and allocation identities to one immutable manifest. Test questions/answers must not enter a training worker; store sealed test IDs separately from fit/response/selection/development payloads. Reference parsing is measurement admission, not model evaluation or tuning. Expose no test solutions in console output.

## Discovery before code

`outcome_score.py` already owns scoring and preserves the closed AIME functions. Add only a guarded wrapper around upstream author functions there. `audit_irc_sources.py` already owns pinned-source checks and reference auditing; add the narrow callable loader there, executing only the AST of the upstream `remove_boxed` function so that historical top-level API configuration never executes. The library wrapper receives callables and returns the existing correct/extracted_answer/parse_status contract.

`splits.py` already owns canonical row identity and deterministic group allocation; extend it only with problem normalization/clustering using scikit-learn and SciPy, not a new approximate-neighbor implementation. `materialize_outcome_score_data.py` already owns SHA-256 helpers and immutable materialization patterns. The new MATH materializer wires these existing operations to the pinned source and exposure inventory. No prior result-generating source or allocation is overwritten. Tests first cover empty guards, exact upstream conformance, transitive clustering, input-order invariance, cross-split exposure exclusion and immutable output.

Historical-only similarity edges need not be computed: every historical vertex is already ineligible. Omitting those edges cannot change whether a MATH component touches history, or the identity of any eligible MATH component. Query only the MATH prefix of the combined frame against all texts, preserving all MATH–MATH and MATH–history edges. Do not interpret disconnected historical vertices as an audit of historical-only duplicate structure. This is a computational equivalence for admission, declared before counts, not a relaxed similarity threshold.
